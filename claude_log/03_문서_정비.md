### README.md
- **폴더 이름**: `address_book`을 모두 `address_book_v2`로 바꿨습니다(폴더 구조, `cd` 경로, 요약 명령).
- **DB 초기화**: 필수 단계였던 "DB 초기화 (최초 1회)" 절을 뺐습니다. 3단계 아래에 "DB는 자동으로 만들어진다"는 안내를 넣고, init-db는 "(선택) DB 테이블만 미리 만들기" 절로 옮겼습니다. 요약 명령에서도 init-db를 뺐습니다.
- **Windows 먼저, Mac 다음**: Python 버전 확인 표, 패키지 설치, 테스트처럼 "모두 같다"며 묶어 두었던 블록을 Windows와 Mac으로 나눴습니다.
- **성공 확인과 막혔을 때**: 설치 0~3단계, 실행, 포트 정리, init-db, 테스트 아래에 각각 넣었습니다.
- **터미널 2개 사용**: 새 절을 추가했고, 실행 절과 테스트 절 제목에 각각 (터미널 ②)와 (터미널 ①)를 붙였습니다. 요약 명령도 터미널별로 나눴습니다.
- **5000번 포트가 이미 사용 중일 때**: 새 절을 넣었습니다. Windows는 `Get-NetTCPConnection`으로 포트를 쓰는 프로그램을 찾고 `Stop-Process`로 끕니다. Mac은 `lsof`와 `kill`을 씁니다. 찾은 프로그램이 python이 아니면 끄지 말고 다른 포트를 쓰라는 안내도 넣었습니다.
- **테스트 개수**: `15 passed`를 `17 passed`로 고쳤습니다. 테스트 표에는 "DB 자동 생성" 줄을 추가했습니다.
- **자주 겪는 문제**: `no such table`의 해결 방법을 init-db 실행에서 "서버를 껐다 다시 켜기"로 바꿨습니다. `Address already in use`는 새 포트 정리 절을 보도록 연결했습니다.
